# 星際課間｜太陽系探索室

繁體中文學生導覽網站，以 Three.js + Vite 實作太陽與八大行星。未改動參考地球專案。

## 開啟

- `solar-system-offline.html`：下載後用現代瀏覽器直接開啟，無外部圖片、字型或 API 依賴。
- 開發：Node.js 22+，`npm ci`、`npm run dev`。
- 驗證：`npm run check`，依序建置、生成離線單檔、執行測試。
- 靜態網站：`dist/` 可部署至子路徑（Vite `--base=./`）。需 HTTP 服務，不要直接開 dist/index.html。
- `?no3d=1` 強制完整 2D 模式；`?planet=mars` 可指定起始天體。

## 操作

- 拖曳旋轉、滾輪或雙指縮放、點選球體；所有天體也有獨立鍵盤按鈕。
- 畫布方向鍵旋轉，＋／−縮放；重設視角。
- 公轉暫停及 1×／5×／20×（1×：每秒 20 地球日）。遵循減少動態效果設定預設暫停。
- 可主動切換 2D；WebGL2 不可用或 context lost 時自動提供 2D 知識導覽。
- 三種線性比較：平均直徑、軌道半長軸、恆星公轉週期；另有真實行星直徑比例圓圖，不含星環。

## 科學範圍

詳見 SOURCES.md 與 src/data.json。數值約值、來源核對日期 2026-10-05。

3D 場景使用壓縮距離、放大球體、圓形共面軌道與任意初始相位；不是即時星曆或精準物理模擬。公轉保留資料週期的相對速度。自轉只為展示程序化表面，沒有科學自轉速度與軸傾角。地表、雲帶、色彩均為程式藝術示意，不是衛星照片。未顯示衛星、矮行星軌道、偏心率、軌道傾角或引力攝動。冥王星分類另附官方介紹。

平均直徑統一採 JPL 體積等效平均半徑 × 2，顯示四捨五入公里；太陽直徑約140萬公里。距離為 J2000 軌道半長軸教育約值，不是當下距離；地球數值採地月質心。公轉週期採 JPL 恆星週期換算地球日。太陽不列入行星比較，避免混淆分類。
