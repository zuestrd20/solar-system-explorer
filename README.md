# 星際課間｜太陽系探索室

繁體中文學生導覽網站，以 Three.js + Vite 實作太陽與八大行星，以及從地球出發的連續宇宙尺度旅程。

## 開啟與建置

- `solar-system-offline.html`：下載後用現代瀏覽器直接開啟，無外部圖片、字型或 API 依賴。
- 開發：Node.js 22+，`npm ci`、`npm run dev`。
- 驗證：`npm run check`，依序建置、生成離線單檔、執行測試。
- 靜態網站：`dist/` 支援子路徑（Vite `--base=./`），需 HTTP 服務。
- `?no3d=1` 強制完整 2D 模式；`?planet=mars` 指定起始天體；`?cosmic=0` 至 `?cosmic=8` 指定連續宇宙尺度位置，可使用小數。

## 保留功能

### 九站連續宇宙旅程

地球 → 地日距離 → 行星區與更遠處 → 比鄰星 → 銀河系 → 本星系群 → 近鄰星系群／星系團 → 宇宙網 → 可觀測宇宙。

- 共同地球觀測錨點、壓縮對數視覺縮放、相鄰尺度逐漸顯露；觀測參考中心不代表宇宙中心。
- 滑桿步長0.01，步進、直接跳層、方向鍵/Home/End、連點與中途反向；從當前位置續播。
- 回到地球及瀏覽器 Back 立即取消舊動畫並恢復指定位置。
- 減少動態效果設定採立即切換。Canvas2D 與 WebGL 共用動畫狀態。
- 近鄰星系與宇宙網採程序發光圖元、節點及絲狀結構，全部是概念示意，不是實際星圖。符號數不代表真實成員數。

### 太陽系探索與比較

- 拖曳旋轉、滾輪／雙指縮放、點選球體；獨立鍵盤天體按鈕。
- 畫布方向鍵旋轉、＋／−縮放、重設視角。
- 公轉暫停與 1×／5×／20×速度（1×每秒20地球日）；尊重減少動態效果。
- WebGL2不可用時完整2D知識導覽。
- 行星平均直徑、軌道半長軸、恆星公轉週期的線性比較，以及真實行星直徑比例圓圖。

## 科學與視覺限制

詳見 SOURCES.md、COSMIC_SOURCES.md、COSMIC_WEB_SOURCES.md 及 src/*data.json。NASA／JPL／ESA來源核對日期2026-10-05。

軌道壓縮、球體放大、圆形共面軌道及任意初相位都只是教學示意；不是星曆或精準物理模擬。公轉保留週期比例，自轉只展示材質。所有地表、星系形狀、位置、色彩及宇宙網絲線均為原創程序示意。

直徑、半長軸、代表成員距離、群／團範圍與觀測半徑分開定義。可觀測宇宙今日半徑約460億光年不等於138億年的宇宙年齡，也不是光行時或物理牆。

## 已移除的區塊

依使用者2026-10-05最新要求，完整移除「把地球縮成一顆小珠子」模型縮尺區，包括0.1–10cm滑桿、四張數值卡、SVG動畫、預設按鈕及專用程式／樣式。Git歷史保留前版本；這不影響九站宇宙旅程與行星比較。
